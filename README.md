# 🎤 Local Web Karaoke & Syllable Studio

> **「在台灣唱日K太貴，那就自己寫一個！」**
> 一個完全在瀏覽器端本機運作的日文卡拉OK播放器與音節時間軸校正工作站。
> 純原生 Single-Page Application，零外部構建依賴，雙擊即唱。

---

## 💡 開發背景：為什麼做這個？

在台灣熱愛動漫歌、J-POP、VOCALOID 或東方 Project 同人音樂的人，想唱正統日系卡拉OK（日K，如 JOYSOUND、DAM）門檻極高——全台實體日K包廂數量稀少、預約不易，加上包廂費與人頭費動輒數百至上千元，想要平時高頻率練歌對荷包負擔極重。

市面上的普通網頁播放器或伴奏工具大多只支援最基礎的純文字 LRC，遇到日文漢字根本無法顯示對唱腔至關重要的**振假名（Furigana / Ruby）**，更遑論日K字幕專用格式（如 MiliKara ASS）的音拍精細變色。

**既然出門唱太貴、市面工具又殘缺，不如自己動手做！**

本專案透過 **Vibe Coding**，以**單一 HTML 檔案**打造出完全在瀏覽器本機執行的專業日K伴唱工作站。不需要安裝複雜後端環境，隨時拖入個人收藏的伴奏、MV 與 ASS 字幕，在家就能享受包廂等級的無痛練唱體驗！

---

## 🌟 核心亮點

* 🌸 **專為日文動漫歌曲打造**：原生支援日文漢字振假名（Ruby）渲染，徹底解決多假名單字錯位問題。
* ⚡ **零依賴單檔架構（Zero-dependency）**：僅由單一 `index.html` 構成，不需 `npm install`、不需後端，支援 GitHub Pages 一鍵發布或本機直接開啟。
* 🔒 **純本機沙盒與隱私保護**：所有使用者載入的伴奏音訊、MV 影片與字幕皆透過瀏覽器沙盒在記憶體中解析，絕不外流或上傳伺服器。
* 🎛️ **Denmoku 多媒體主控台**：支援獨立伴奏與背景影片同時載入，具備自動防打架靜音管理與動態資源卸載釋放（`URL.revokeObjectURL`）。
* 🛠️ **內建 DAW 音節調校工作站**：提供側邊可收合的「音節校正抽屜」，支援敲擊空白鍵跟唱打點（Tap-to-Sync）及時間軸專案 JSON 匯入匯出。
* 📦 **開箱即測體驗包**：提供測試用**完全去人聲伴奏、降低人聲伴奏**與精密校正的 **ASS 日K字幕**，無需自行準備素材即可直接體驗。

## 📑 核心技術功能

### 1. 智慧 ASS / LRC 字幕解析引擎

* **MiliKara 同行聚合**：將 ASS 中以單詞切分的零碎 `Dialogue` 事件，依起始時間與水平基準線自動聚合成完整唱句，徹底杜絕斷句碎裂。
* **Word-level Ruby 振假名精準對齊**：徹底解決一漢字對多平假名（如「通[とお]」、「鏡[かがみ]」）時單字元抽取造成的骨牌式位移；亦支援複合詞分離（如「越[こ]えて」）。
* **前置時間補償（Zero-Latency）**：精準抽離前置等待標籤（如 `{\k300}`），消除字幕滯後感，達成字幕抹色與音樂第一拍的零延遲咬合。

### 2. 卡拉OK動態舞台渲染

* **雙行上下交替路徑**：奇數句與偶數句上下行輪流進場，提供最自然的卡拉OK視線移動與視唱引導。
* **60 FPS 平滑變色（Wipe Animation）**：採用動態計算之 CSS `clip-path: inset(0 X% 0 0)`，依個別音節持續時間（`dur`）平滑抹色。
* **4.0 秒門檻與長間奏乾淨畫面**：未滿 4 秒前保持畫面純淨（只播背景影片），不在螢幕前置文字發呆。
* **智慧引導倒數燈**：僅在長前奏或大於 4 秒的顯著長間奏期間，於開唱前 1.8 秒啟動三段式節奏紅點燈；短間奏自動靜音隱藏。
* **句中跳轉即時掛載（Mid-sentence Seek）**：任意拖曳時間軸進度條跳轉至唱句正中間時，系統立即強制掛載文字與注音，並同步補足當下變色進度。

### 3. 多媒體控制與 Web Audio 引擎

* **多媒體優先級防衝突**：支援同時載入背景影片與獨立伴奏音訊。伴奏存在時自動將影片靜音，由伴奏音訊主導；伴奏卸載後自動恢復影片原音。
* **獨立動態卸載機制**：背景影片、伴奏音訊、對齊字幕（JSON/ASS）皆具備獨立複合按鈕，載入後動態浮現「✕」卸載按鈕，一鍵釋放記憶體。
* **即時麥克風殘響（Mic & Echo）**：透過 Web Audio API 串接麥克風輸入，內建低通/高通濾波與延遲回饋效果器。
* **和弦合成器備援**：未載入任何外部音訊時，自動啟動內建三角波四和弦合成器輔助對齊。

### 4. DAW 音節編輯抽屜（Syllable Studio）

* **即時時間軸卡片**：展開可檢視全曲每行與各音節的字元、注音與時長。
* **單字微調控制**：支援音節時長以 ±0.05s（微調）或 ±0.2s（粗調）進行加減，並可微調句子起點。
* **空白鍵打點同步（Tap-to-Sync）**：播放中敲擊 `Space` 空白鍵即可一邊跟唱一邊逐字記錄節拍。
* **專案匯出**：可一鍵導出標準卡拉OK專案 JSON，方便日後重複載入與調教。

## 🎮 使用流程

1. **載入媒體與字幕**：
* 點擊 **`📂 影片`**：選擇本地 MV 或背景動畫（選用，支援 `.mp4`、`.webm`）。
* 點擊 **`🎵 伴奏`**：選擇去人聲伴奏（可使用雲端提供的完全去人聲或降低人聲伴奏檔）。
* 點擊 **`📥 匯入對齊 (JSON/ASS)`**：載入包含音拍對齊資訊的 `.ass` 或 `.json` 檔案（亦可點擊 **`📝 LRC`** 載入簡易歌詞）。


2. **播放與互動**：
* 點擊 **`▶ 播放`** 或直接**點擊主舞台中央**開始/暫停播放。
* 使用方向鍵 `←` / `→` 可快退/快進 1 秒（按住 `Shift` 為 5 秒）。


3. **伴唱與殘響**：
* 點擊 **`🎤 麥克風`** 授權錄音權限，並滑動「回音」滑桿調整空間殘響感。


4. **校正時間軸**：
* 點擊 **`🛠 軌道編輯`** 開啟調校抽屜，敲擊 `Space` 鍵打點或透過按鈕微調時長，滿意後點擊「💾 匯出卡拉OK專案 JSON」。
